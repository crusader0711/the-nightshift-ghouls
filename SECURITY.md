# Security Policy

## Supported versions
Only the latest state of `main` (and the most recent release, if tagged) receives fixes.

## Reporting a vulnerability
Please **do not open a public issue**. Report privately through GitHub's
[private vulnerability reporting](https://github.com/crusader0711/the-nightshift-ghouls/security/advisories/new)
(repository **Security** tab → **Report a vulnerability**).

Include what you found, how to reproduce it, and the impact you expect.

## Disclosure
We follow **90-day coordinated disclosure**: we acknowledge reports within 7 days, aim to ship a fix
within 90 days, and agree a publication date with the reporter. Credit is given unless you ask otherwise.

## Integrity
Release artifacts are listed in `RELEASE_MANIFEST.json` and hashed in `SHA256SUMS`;
verify with `sha256sum -c SHA256SUMS`.
