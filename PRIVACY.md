# Privacy

The Nightshift Ghouls is a **static site**: HTML, CSS, JavaScript and images served by GitHub Pages.

- **No backend, no accounts, no cookies set by this project, no analytics or telemetry.**
- **No credentials** are stored in or required by this repository.
- All data shown is static content committed in `js/data.js`; nothing you do on the page is sent anywhere by this project.
- The page loads Tailwind CSS from `cdn.tailwindcss.com` and the JetBrains Mono font from Google Fonts. Those
  providers receive standard request data (IP address, user agent) under their own privacy policies.
- GitHub Pages hosting is subject to GitHub's privacy statement.
- Images have had embedded metadata (EXIF/GPS) stripped.
